## Plantilla

Contexto → decisión → alternativas → consecuencias → evidencia necesaria → condición de revisión.

Separar decisiones aprobadas por el usuario de parámetros de diseño todavía experimentales. Ninguna decisión aquí implica que el sistema esté implementado.
